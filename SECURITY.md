# Security

UDC is a pure library. It does not authenticate, authorize access to datasets, fetch remote resources or enforce tenant isolation. Those responsibilities belong to its host application. Do not use dataset IDs or content hashes as access tokens.

To report a security vulnerability privately, use GitHub's security-advisory reporting feature for this repository when enabled. If that feature is not enabled, contact repository maintainers privately instead of posting exploit details in a public issue.

Please include affected versions, reproduction details and impact while avoiding real customer data.
